## 2. Как читать `.dc.html`

Это прототипы, не продакшн-код. Переносите разметку и стили, а логику не копируйте.
- Разметка лежит между `<x-dc>` и `</x-dc>`. Стили инлайн, все значения берутся из `var(--…)`.
- `{{ name }}` — данные. `<sc-for list as>` — цикл, `<sc-if value>` — условие.
- `class Component` в `<script data-dc-script>` — демо-логика и моковые данные (`STUDENTS` и т. п.).
  Метод `themeVals()` показывает, что зависит от темы в JS.
- `data-screen-label` — код экрана (S…/T…), см. §5.
- Инлайн-стили при переносе превращайте в классы/компоненты вашего стека. Значения при этом не меняйте.

## 3. Темы

| id | Название | Шрифты (display / UI) |
|---|---|---|
| `notebook` | Тетрадь отличника (по умолчанию) | Literata / Onest |
| `quest` | Звёздный квест | Unbounded / Nunito |
| `sky` | Созвездие | Geologica |
| `clear` | Ясно и быстро | Golos Text |
| `sticker` | Стикербук | Rubik + Caveat (рукописные подписи) |
| все | цифры кодов | JetBrains Mono |

**Атрибуты:**
- `<html data-theme="notebook|quest|sky|clear|sticker">`
- `clear`: ещё `data-mode="light|dark|auto"`. `auto` = `prefers-color-scheme`, в Telegram — `Telegram.WebApp.colorScheme`.
- `sky`: по умолчанию дневная палитра (учитель, печать). У контейнера `data-night` — ночная (кабинет ученика, вход учителя). `data-day` внутри `data-night` возвращает дневную (карточка входа).
- `data-light` — всегда светлая палитра (печать в любой теме).

**Тематические переключатели в токенах.** Элементы, которые есть только в одной теме, показываются через
`display: var(--show-nb | --show-q | --show-sky | --show-clear | --show-stk)` (и `*-flex`).
Сохраните этот механизм или замените условиями в шаблоне. Тексты и логику при этом не трогайте.

**Где хранить.** На сервере: тема — в профиле ученика / настройке класса, режим clear — у пользователя.
`data-theme` рендерить в `<html>` сервером, чтобы при загрузке не мигала чужая тема.
`localStorage` (`zvezdy-theme`, `zvezdy-mode`) — только как запасной вариант.

**Шрифты** хранить локально, woff2, cyrillic + latin, `font-display: swap`. Google Fonts не использовать: в школьной сети медленно.

## 6. Различия разметки между темами

Общее для всех тем: структура экранов, тексты, данные, функции.
- **Боковая панель ученика (T1):** `sky`, `clear`, `sticker`. В `notebook` и `quest` её нет: данные входа показаны в таблице/меню.
- **Ввод звёзд (T1):** `clear` — сегментный переключатель 0–5 и подсказки клавиш. Остальные темы — кнопки-звёзды.
  У `clear` своя сетка колонок таблицы (см. `cols` в логике).
- **Клавиатура учителя:** цифры 0–5 ставят звёзды, ↑/↓ и Enter переходят к следующему ученику.
- **Классы:** `sticker` — цветные вкладки классов.
- **Фото призов:** `quest` 1:1, остальные 4:3 (`--photo-ar`).
- **Фон:** `sky` — звёздное небо и созвездия на кабинете ученика (`--sky`), у `notebook` — тетрадная линейка (`--rule`).
- **Тёмный режим** есть только у `clear` (light/dark/auto) и у ночной палитры `sky`.
- **Печать:** во всех темах светлая, ч/б-совместимая. Есть выборочная печать и ч/б-предпросмотр.

Сверяйте каждую тему по самому макету: в прототипе вверху есть переключатель тем.
