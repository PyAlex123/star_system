# Воплощение дизайна в Claude Code

## 1. Подготовка репозитория

1. Положите все md-файлы в репозиторий: `docs/design/` (00–05 + этот файл).
2. Добавьте в `CLAUDE.md` проекта блок:

```markdown
## Дизайн
Дизайн-вариант: 05-stikerbuk          <!-- замените на выбранный -->
Источники правды: docs/design/00-brief-obshchiy.md + docs/design/<вариант>.md
Приоритет при расхождениях: handoff-бандл Claude Design > файл варианта > общий бриф.
Все цвета, шрифты, радиусы, тени — только из static/css/tokens.css.
Иконки — инлайн-SVG; эмодзи не использовать как кнопки.
Не менять бэкенд, API и логику начисления/списания звёзд без прямой просьбы.
После любой правки UI — визуальная проверка 390×844 и 1440×900.
```

## 2. Два пути из Claude Design в код

**Путь А — Handoff (основной).** В Claude Design: Export → Handoff to Claude Code. Claude упакует макет, компоненты, стили и тексты в бандл, который передаётся в локальный Claude Code или в Claude Code в вебе одной командой.

**Путь Б — команда `/design` в Claude Code.** Позволяет создавать, редактировать и синхронизировать дизайн-проекты прямо из терминала и импортировать дизайн в кодовую базу. Если команды нет: выполните `/update` и откройте новую сессию.

`/design-sync` вам, скорее всего, **не нужен**: он переносит дизайн-систему из React-компонентов (Storybook или npm-пакет) в Claude Design. Он пригодится, только если фронтенд переедет на React.

## 3. Скилы, плагины и MCP

### Обязательно

**1. `frontend-design` (Anthropic, официальный)** — даёт Claude дизайн-процесс перед написанием UI-кода: типографика, палитра, раскладка, движение, без «шаблонного AI-вида».
```
/plugin marketplace add anthropics/claude-code
/plugin install frontend-design@claude-code-plugins
```
⚠️ Этот скил сам выбирает эстетическое направление. Стиль у вас уже выбран, поэтому в каждом промпте пишите: *«Стиль задан в docs/design/<вариант>.md — следуй ему, своё направление не придумывай»*.

**2. Playwright MCP (Microsoft)** — настоящий браузер для Claude Code: открывает страницы, кликает, делает скриншоты на нужной ширине, эмулирует печать.
```
claude mcp add playwright npx @playwright/mcp@latest
```

### Желательно

**3. `webapp-testing` (Anthropic, из набора example-skills)** — сценарии на Python Playwright: поднимает локальный сервер, снимает скриншоты, читает логи консоли. Удобно для повторяемых проверок «до/после».
```
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
```

### Свои скилы под проект (предложены карточкой в чате)

| Скил | Что делает |
|---|---|
| `zvezdy-ui-implement` | Порядок внедрения выбранного варианта: tokens.css → шрифты → иконки → компоненты → экраны. Жёсткие правила проекта: склонения, ★ рядом с числом, Telegram, печать А4, без эмодзи-кнопок, бэкенд не трогать |
| `zvezdy-ui-qa` | Визуальная проверка после правок: скриншоты ученика 390×844, учителя 1440×900 и 1280×800, PDF печати А4, стресс-данные, чек-лист, отчёт с проблемами по серьёзности |

## 4. План внедрения (по этапам, каждый — отдельный PR)

| Этап | Что | Готово, когда |
|---|---|---|
| 0 | Снимки текущих экранов («до») | Есть папка `docs/design/qa/before/` |
| 1 | `tokens.css`, шрифты (self-host woff2, кириллица), спрайт иконок | Страница-витрина компонентов открывается локально |
| 2 | Базовые компоненты | Кнопки, чипы, пилюля баланса, прогресс, карточка приза, ввод 0–5, модалка, шторка, тост |
| 3 | Кабинет ученика S1–S5a + S0 | Скриншоты 390×844 совпадают с макетом, нет горизонтальной прокрутки |
| 4 | Панель учителя T1, T1a, T2, T2a, T2b, T0, T3 | Урок на 10 учеников проводится без мыши (если вариант это предполагает) |
| 5 | Печать T4 | PDF А4: 8 карточек, ч/б, QR ≥ 30 мм |
| 6 | Праздники и микро-анимации, `prefers-reduced-motion` | Отключаются при reduced motion |
| 7 | Финальный QA | Отчёт `zvezdy-ui-qa` без критичных проблем |

Шрифты лучше хранить локально, а не грузить с Google Fonts: в школьной сети интернет бывает медленным.

## 5. Готовые промпты для Claude Code

**Старт (после Handoff):**
```
Прочитай CLAUDE.md, docs/design/00-brief-obshchiy.md и файл выбранного
варианта. Изучи handoff-бандл Claude Design. Найди в проекте шаблоны и CSS
кабинета ученика, панели учителя и карточек печати. Составь план по этапам
из docs/design/06-claude-code-vnedrenie.md, покажи его и жди подтверждения.
Бэкенд и API не меняй.
```

**Этап 1:**
```
Используй скил zvezdy-ui-implement. Сделай этап 1: создай static/css/tokens.css
из токенов варианта, подключи шрифты локально (woff2, cyrillic+latin),
собери SVG-спрайт иконок для всех действий из брифа. Сделай служебную
страницу /_ui с образцами цветов, шрифтов и иконок. Проверь её скилом zvezdy-ui-qa.
```

**Экран:**
```
Сверстай экран S2 «Призы» строго по макету из handoff и разделу S2 файла
варианта. Используй только токены. Состояния: хватает / не хватает /
пусто / загрузка. После — скриншоты 360, 390 и 430 px и сравнение с макетом.
```

**Учительская таблица:**
```
Переделай таблицу журнала по разделу T1 варианта: видимые действия — QR
и «Выдать приз», остальные в меню «⋯» с подписями; колонку «Вход» убери
в боковую панель; добавь ввод звёзд цифрами 0–5 и переход Enter/↓ к следующему
ученику; липкий низ с итогом и диалог-подтверждение перед начислением.
Логику начисления не меняй, только UI.
```
