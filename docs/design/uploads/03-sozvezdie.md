# Вариант 3 — «Созвездие»

> Прикладывать вместе с `00-brief-obshchiy.md`. Визуальные решения этого файла важнее общего брифа.

## Идея
Звёзды — буквально звёзды. Кабинет ученика — ночное небо, каждая заработанная звезда зажигает точку в личном созвездии, а приз — это созвездие, которое нужно «дорисовать». В наборе аватаров уже есть космонавт, ракета, планета, инопланетянин и робот: тема ложится на то, что у вас уже есть. Кабинет ученика тёмный, панель учителя светлая («дневное небо»), печать белая.

**Выбирать, если:** нужен «вау» и самый узнаваемый образ; многие дети пользуются Telegram в тёмной теме.
**Риск:** тёмные интерфейсы сложнее рисовать хорошо. Нужна дисциплина: никаких неоновых свечений на каждом элементе, фон звёздного неба статичный.

**Настроение:** ночное небо · созвездие · обсерватория · тишина · свечение · открытие.

## Токены

```css
/* Кабинет ученика — ночь */
:root[data-theme="night"] {
  --color-bg:         #0A0F24;   /* ночное небо */
  --color-surface:    #131A38;   /* карточки */
  --color-surface-2:  #1B2450;   /* вложенные, активные */
  --color-line:       rgba(255,255,255,.09);
  --color-text:       #EEF1FF;
  --color-text-muted: #A3ACD0;   /* 7.6:1 на surface */

  --color-star:       #FFD166;   /* звёзды, баланс, цены */
  --color-primary:    #5CE1E6;   /* кнопки — «бирюза туманности» */
  --color-on-primary: #04212A;
```

Контраст проверен: текст на ночном фоне 16.9:1, приглушённый 7.6:1, звезда на карточке 11.8:1, тёмный текст на бирюзовой кнопке 10.6:1.

## Форма и детали
- **Звёздное небо:** 2–3 слоя мелких точек через CSS `radial-gradient` (статичная картинка, не canvas), плотность низкая. Мерцают только 3 точки (opacity 0.4 ↔ 1, 4 с). Без мерцания при `reduced-motion`.
- **Созвездие прогресса:** для цели-приза рисуем созвездие из N точек (N = 10 сегментов цены). Зажжённые точки соединены линиями, остальные — тусклые кружки. Это главный визуальный приём варианта.
- **Карточки:** `--color-surface` с границей `--color-line`, без теней (на тёмном тени не видны). Глубина — через светлее/темнее.
- **Иконки:** Lucide, линия 1.75 px, цвет `--color-text-muted`, активные — `--color-star`.
- **Свечение** только у баланса и у только что зажжённой звезды. Больше нигде.

## Кабинет ученика

**S1. Шапка «Обсерватория»**
- Фон — то же небо, без отдельной плашки.
- Аватар 64 px с тонкой орбитой-кольцом (`--color-nebula`), имя, чипы.
- Баланс крупно, золотом, со звездой.
- Под балансом **созвездие цели**: 10 точек в форме фигуры (ковш, стрела, корона — фигура зависит от категории приза), 8 из 10 горят. Подпись: «Созвездие «Стандартный набор «Знаток»» — зажги ещё 11 ★».
- На других вкладках мини-шапка 56 px.

**S2. Призы — «Звёздная карта»**
- Переключатель «Все / Доступны» — таблетка `--color-surface-2`, активная бирюзовая.
- Карточки 2 колонки: фото 1:1 на тёмной подложке со скруглением 14 px, цена — золотая пилюля.
- **Доступно:** тонкая золотая рамка, бейдж «Можно забрать» с иконкой-галочкой, мягкое свечение рамки.
- **Недоступно:** мини-созвездие прогресса вместо полоски.

**S3. Рейтинг**
- Пьедестал как три «планеты» на орбите: самая большая — 1 место. Цвета кромок — золото, серебро-лаванда, медь. Аватары внутри планет.
- Список: карточки `--color-surface`. Моя строка — рамка `--color-nebula` и подпись «Это ты».
- Плашка: «До 6-го места — 3 звезды. Почти рядом!» с иконкой телескопа.

**S4. История — «Журнал наблюдений»:** вертикальная тонкая линия-орбита слева, на ней точки-события. Начисления — золотые звёзды «+5», списания — планета-подарок «−12» серым.

**S5. Профиль:** аватары на тёмных кругах, выбранный с орбитой-кольцом. Космические аватары (космонавт, ракета, планета, инопланетянин) в начале сетки.

**Праздник «хватает на приз»:** созвездие дорисовывается: последняя точка зажигается, линии пробегают по фигуре за 600 мс, появляется надпись «Созвездие собрано! Можно забрать приз», кнопка «Покажу учителю».

**Telegram:** кабинет всегда в ночной теме (свой фон), шапка Telegram — `#0A0F24`.

## Панель учителя («дневное небо»)

**T1. Журнал**
- Светлая тема, индиго-кнопки, золото только для звёзд.
- Шапка урока: дата · «Банк урока» как ряд из 10 звёзд-контуров (потраченные залиты золотом) · «Импорт / Экспорт» в одном меню.
- Классы — таблетки. Школа — выпадающий список с действиями внутри («Переименовать», «Удалить»), а не тремя отдельными кнопками.
- Таблица плотная (строка 52 px):
  - звёзды за урок — 5 контурных звёзд, заливка золотом; поддержка клавиш 0–5 и ↑/↓;
  - баланс — число `--color-star-text`;
  - вход — код в моноширинной «плашке»; логин и пароль по клику;
  - действия: «QR», «Выдать приз», «⋯».
- **Боковая панель ученика** (по клику на строку, 400 px справа): большой аватар, баланс, история, QR, логин/пароль, выдача приза, опасная зона. Таблица остаётся видимой.
- Липкий низ с итогом и кнопкой «Завершить урок».

**T2. Призы:** белые карточки, фото 4:3, цена золотом. Модалка с загрузкой фото перетаскиванием.

**T0. Вход:** единственный тёмный экран панели — ночное небо и белая карточка входа по центру. Это мостик к детскому кабинету.

## Печать (T4)
- Белый фон, тёмно-индиго линии, **никаких тёмных заливок** (экономия краски).
- На каждой карточке маленькое контурное созвездие в углу.
- QR 32 мм, код моноширинным, блок сайта под пунктиром. 8 карточек на А4.

## Движение
Медленно и плавно: 220–320 мс, `cubic-bezier(.2,.8,.2,1)`. Мерцание 3 звёзд фона, зажигание точек созвездия, дорисовка линий при празднике. Никакой тряски и пружин.

## Не делать
- Неоновое свечение на кнопках и карточках.
- Анимированное небо на canvas: батарея и слабые телефоны.
- Тёмную тему в печати.
- Фиолетовый как основной цвет: туманность — только акцент.
- Чистый чёрный `#000` для фона.
