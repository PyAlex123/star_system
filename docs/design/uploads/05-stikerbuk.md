# Вариант 5 — «Стикербук»

> Прикладывать вместе с `00-brief-obshchiy.md`. Визуальные решения этого файла важнее общего брифа.

## Идея
Тетрадь в клетку, в которую ребёнок клеит наклейки. Звёзды — наклейки-штампы, призы — стикеры с полосками скотча, рейтинг — доска почёта из вырезанных картинок. Жирные чёрные контуры, плоские яркие цвета, жёсткие тени без размытия (необрутализм для детей). Стиль очень контрастный, поэтому хорошо читается и **отлично печатается в ч/б**: карточки входа выглядят как настоящие наклейки.

**Выбирать, если:** нужен самый узнаваемый и «детский, но не малышовый» стиль; хочется, чтобы карточки и плакаты в классе были в том же стиле, что и бот.
**Риск:** хаос, если переборщить с наклоном и цветами. Правила ниже обязательны.

**Настроение:** наклейки · тетрадь в клетку · скотч · маркер · штамп · «сделано руками» · весело.

## Токены

```css
:root {
  --color-paper:      #FFFDF5;  /* фон */
  --color-grid:       #E6ECF5;  /* клетка 24 px */
  --color-surface:    #FFFFFF;
  --color-ink:        #121212;  /* контуры, текст, тени */
  --color-ink-muted:  #4B4B4B;  /* 8.6:1 на бумаге */

  /* наклейки: на всех тёмный текст, контраст 6.7–13:1 */
  --color-yellow: #FFD23F;  /* звёзды, баланс */
  --color-coral:  #FF6B5B;  /* опасные действия, «не хватает» */
  --color-mint:   #3DD598;  /* «можно забрать», успех */
  --color-sky:    #4DA8FF;  /* основной для кнопок */
  --color-lilac:  #B69CFF;  /* «это ты», выбор */
  --color-pink:   #FF8FC7;  /* декор, редко */

  --border:        2px solid var(--color-ink);
  --shadow-hard:   3px 3px 0 var(--color-ink);   /* карточки */
  --shadow-btn:    4px 4px 0 var(--color-ink);   /* кнопки */
  --shadow-press:  1px 1px 0 var(--color-ink);   /* нажатие: сдвиг на 3 px */

  --radius-md: 14px; --radius-lg: 20px; --radius-pill: 999px;

  --font-ui:    "Rubik", system-ui, sans-serif;
  --font-hand:  "Caveat", cursive;     /* только рукописные пометки */
  --font-mono:  "JetBrains Mono", ui-monospace, monospace;

```

Фон-клетка — CSS-градиент:
`background-image: linear-gradient(var(--color-grid) 1px, transparent 1px), linear-gradient(90deg, var(--color-grid) 1px, transparent 1px); background-size: 24px 24px;`

**Правило Caveat:** не больше 2 пометок на экран, только как декор рядом с основным текстом, никогда вместо него.

## Правила, чтобы не было хаоса
1. **Наклон** (±1.5°) — только у декоративных наклеек: фото приза, аватары на доске почёта, бейджи. Текстовые блоки, кнопки и таблицы всегда ровные.
2. **Один яркий цвет на компонент.** Карточка белая; цвет у одной её детали (лента, бейдж, кнопка).
3. **Одна толщина контура** — 2 px. Одна жёсткая тень для карточек (3 px) и одна для кнопок (4 px).
4. **Клетка** только на фоне страницы, не внутри карточек.
5. В учительской панели: без наклонов, без Caveat, клетка только в шапке.

## Форма и детали
- **Кнопки:** белые или цветные, контур 2 px, тень 4 px. При нажатии сдвиг вниз-вправо на 3 px, тень 1 px. Главная кнопка — `--color-sky`.
- **Скотч:** полупрозрачные полоски (`rgba(255,210,63,.6)`, слегка неровные края через SVG-маску) крепят фото призов к карточкам.
- **Звезда-наклейка:** жёлтая звезда с чёрным контуром 2 px и белой «высечкой» 3 px вокруг, как у вырубленной наклейки.
- **Иконки:** Phosphor Bold, 22 px, цвет `--color-ink`.
- **Аватары:** белая высечка 3 px + чёрный контур 2 px: выглядят как наклейки.

## Кабинет ученика

**S1. Шапка — обложка тетради**
- Фон — жёлтая обложка `--color-yellow` с контуром снизу; на ней белая «наклейка-именная табличка» с аватаром, ФИО и чипами (школа, класс, место).
- Баланс — большая звезда-наклейка с числом **39** внутри и подписью «звёзд».
- Прогресс к призу как **линейка-шкала**: ряд из 10 клеточек-ячеек, заполненные закрашены маркером (`--color-sky`), на конце наклейка-фото приза. Рукописная пометка Caveat: «ещё 11 — почти!».
- На других вкладках мини-шапка 60 px: аватар-наклейка, имя, «★ 39».

**S2. Призы**
- Переключатель «Все / Уже можно (3)» — две кнопки-наклейки, активная залита `--color-sky`.
- Карточка: белая, контур, жёсткая тень. Фото 1:1 приклеено полоской скотча и наклонено на ±1° (чередовать). Цена — жёлтая наклейка-звезда в углу, заходит за край карточки.
  - **Можно забрать:** мятная плашка внизу «Можно забрать — подойди к учителю» с галочкой.
  - **Не хватает:** коралловый контурный бейдж «ещё 11 ★» и линейка прогресса.

**S3. Рейтинг — «Доска почёта»**
- Три аватара-наклейки, приклеенные на доску (пробковый оттенок `#E9C79B` с контуром), с ленточками-медалями 1/2/3 (золото = `--color-yellow`, серебро = `#D9DEE7`, бронза = `#E8A66F`).
- Ниже список карточек-полосок. Моя строка залита `--color-lilac` и подписана «это ты!» (Caveat).
- Плашка-задание: тетрадный листок с загнутым уголком: «Ещё 3 ★ — и ты на 6-м месте».

**S4. История:** страница тетради. Каждое начисление — штамп-звезда «+5» и надпись «Урок, 18 ноября». Списание — наклейка подарка «−12» и надпись «Приз: светодиоды». Даты как заголовки на полях.

**S5. Профиль:** аватары-наклейки в сетке 4×N. Выбранный приподнят: тень 6 px, наклон 0°, сиреневая высечка. «Своё фото» — кнопка с иконкой камеры. Ниже блок «Мои наклейки» с полученными призами (вырезанные силуэты).

**Праздник «хватает на приз»:** на экран «прилетает» большая наклейка приза (scale 0 → 1.08 → 1, поворот −8° → −2°), сверху штамп «МОЖНО ЗАБРАТЬ!» (scale 1.6 → 1, 200 мс), вокруг 8 маленьких звёзд-наклеек. Кнопка «Покажу учителю».

## Панель учителя — «Классный журнал в стиле стикербука»
Тот же язык, но строже: контуры и жёсткие тени остаются, наклонов и рукописного шрифта нет.

**T1. Журнал**
- Шапка с клеткой и логотипом-наклейкой, вкладки — кнопки-наклейки.
- Панель урока: дата, «Банк урока» — 10 звёзд-наклеек в ряд (потраченные становятся серыми контурами), меню «Импорт / Экспорт».
- Классы — кнопки-ярлычки, как цветные закладки в тетради (у каждого класса свой цвет из палитры; этот цвет повторяется на печатных карточках класса).
- Таблица: белая, контур 2 px вокруг всей таблицы, строки разделены линией 1 px `--color-grid`.
  - Звёзды за урок — 5 звёзд-кнопок 28 px (контур → жёлтая заливка) + число;
  - баланс — жёлтая пилюля с контуром;
  - вход: код в моно-плашке, остальное в боковой панели;
  - действия: «QR», «Выдать» и «⋯» с подписями.
- Главная кнопка «Завершить урок и начислить» — `--color-mint`, тень 4 px, во всю правую часть липкого низа.

**T2. Призы:** карточки как у ученика, но без наклона. Модалка: контур, жёсткая тень, зона фото с пунктирным контуром «Перетащи фото сюда».

**T0. Вход:** белая карточка-наклейка по центру клетчатого фона, звезда-наклейка сверху.

## Печать (T4) — главный козырь варианта
- Каждая карточка — **наклейка с высечкой**: скруглённый прямоугольник с контуром 2 px, вокруг пунктир «вырезать здесь» на 3 мм.
- Сверху ярлычок цвета класса (в ч/б — штриховка), ФИО в Rubik 800.
- QR 32 мм в белой рамке-наклейке, код крупно моноширинным по сегментам `PZ8J TFRQ`.
- Блок «Без Telegram» как приклеенный листочек.
- 8 штук на А4. Выглядит как лист наклеек, детям хочется его получить.
- Бонус для Claude Design: плакат А3 для класса «Как получить звёзды и призы» в том же стиле.

## Движение
Задорно, но коротко: 150–220 мс, `cubic-bezier(.34,1.56,.64,1)` для «наклеивания», `ease-out` для остального. Нажатие кнопок — сдвиг с тенью.

## Не делать
- Наклон текстовых блоков, таблиц и кнопок.
- Больше одного яркого цвета внутри одной карточки.
- Caveat в длинных текстах, кнопках и таблицах.
- Размытые тени: только жёсткие.
- Клетку внутри карточек.
