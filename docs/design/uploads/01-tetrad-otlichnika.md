# Вариант 1 — «Тетрадь отличника»

> Прикладывать вместе с `00-brief-obshchiy.md`. Визуальные решения этого файла важнее общего брифа.

## Идея
Взрослая, благородная эволюция старой зелёной версии: хорошо свёрстанный школьный дневник, где звезда — золотая печать за заслугу. Сохраняем узнаваемость (изумрудные чернила, бумага, золото) и исправляем всё, что мешало: огромную шапку, безымянные иконки, перегруженную таблицу.

**Выбирать, если:** нравится старая версия и нужен минимум риска; школа ценит «серьёзный» вид; систему увидят родители и администрация.
**Риск:** для 10–12 лет может быть суховато, поэтому радость добавляем точечно: штампы, печати, праздник «хватает».

**Настроение:** дневник · печать · бумага · чернила · золото · спокойствие · уважение.

## Токены

```css
:root {
  /* бумага и поверхности */
  --color-bg:          #F4EFE6;  /* бумага */
  --color-surface:     #FFFDF8;  /* карточки */
  --color-surface-2:   #FAF6EE;  /* вложенные блоки, зебра таблицы */
  --color-line:        #E4DCCB;  /* линейки, границы */

  /* чернила (бренд) */
  --color-ink-900:     #14533F;  /* шапка, главные кнопки */
  --color-ink-700:     #1D6A52;  /* hover */
  --color-ink-100:     #E3EEE8;  /* выделение «это ты», активный таб */
  --color-on-ink:      #FFFFFF;
  --color-on-ink-muted:#B9D3C7;

  /* текст */
  --color-text:        #1B2420;
  --color-text-muted:  #5B6660;

  /* звезда / золото */
  --color-star:        #E3A21A;  /* только иконки и полосы прогресса */
  --color-star-text:   #8A5A00;  /* числа «+5», цены на светлом */
  --color-star-bg:     #FBF0D6;

  /* статусы */
  --color-success:     #1F7A4D;
  --color-danger:      #B23A2A;

  /* пьедестал */
  --podium-1: #E3A21A; --podium-2: #A3AEA8; --podium-3: #B9763C;

  /* форма */
  --radius-sm: 8px; --radius-md: 12px; --radius-lg: 18px; --radius-pill: 999px;
  --shadow-card: 0 1px 0 rgba(20,83,63,.06), 0 6px 18px -10px rgba(20,83,63,.25);
  --space: 4px; /* шкала 4/8/12/16/20/24/32/40 */

  --font-ui:      "Onest", system-ui, sans-serif;
```

Контраст проверен: текст на бумаге 13.9:1, приглушённый текст 5.2:1, белый на чернилах 9:1, `--color-star-text` на светлом 5.8:1. Чистое золото `#E3A21A` на тёмно-зелёном даёт 4:1, поэтому оно только для иконок и крупных цифр, не для мелкого текста.

## Форма и детали
- **Тетрадная линейка:** на бумажном фоне еле заметные горизонтальные линии через 28 px (`--color-line`, 40% прозрачности) только в пустых состояниях и в «Истории». Не под таблицей.
- **Звезда-печать:** звезда в двойном круге, как штамп «Отлично». Используется в истории (+5), на карточке «приз выдан» и на печатной карточке.
- **Карточки** с тонкой границей `--color-line`, мягкой тенью и радиусом 18 px.
- **Иконки:** Lucide, линия 1.75 px.
- **Аватары-герои** остаются как есть, с кольцом 3 px цвета бумаги и тонкой внешней линией.

## Кабинет ученика

**S1. Шапка**
- На вкладке «Призы»: полная шапка (тёмно-зелёная, высота ~260 px), баланс 56 px, прогресс к призу.
- Прогресс-бар: золотая полоса на тёмном треке, на конце миниатюра приза 28 px.
- Строку «осталось 11 ★» не переносить: число и звезда в одном блоке.
- На «Рейтинге», «Истории» и «Профиле»: **мини-шапка 60 px** (аватар 32, имя, золотая пилюля «★ 39»). Та же мини-шапка появляется на «Призах» при прокрутке, с плавным переходом.

**S2. Призы**
- Сегментный переключатель «Все / Уже доступны (3)» с отступами 16 px от краёв.
- Сетка 2 колонки, фото 4:3 (не квадрат, чтобы помещалось 3–4 карточки).
- Цена — пилюля на фото слева сверху. Статус «Хватает» — зелёная лента-закладка справа, как закладка в книге.
- Если звёзд не хватает: вместо ленты тонкий прогресс под названием и текст «ещё 11 ★».
- Доступные призы сортируются первыми.

**S3. Рейтинг**
- Пьедестал из трёх «стопок бумаги» разной высоты. Цвет верхней кромки и медали: золото / серебро / бронза.
- Под пьедесталом список с номерами в Literata. Строка «это ты» на фоне `--color-ink-100` с тонкой левой полосой чернил.
- Мотивационная плашка как закладка с иконкой мишени: «Ещё 3 звезды — и ты поднимешься на 6-е место».

**S4. История**
- Лента с датами-разделителями («18 ноября, вторник»).
- Начисление: штамп-звезда и «+5» цветом `--color-star-text`.
- Списание: иконка подарка, «−12» цветом `--color-text-muted` и подпись «Приз: набор светодиодов».

**S5. Профиль / S5a. Шторка**
- Сетка 4 колонки (на 390 px) с отступом 12 px. Выбранный аватар: кольцо чернил 3 px и галочка.
- «Своё фото» — вторичная кнопка с иконкой камеры. «Готово» — главная.

**Праздник «хватает на приз»:** при первом входе после нужного начисления появляется лист-сертификат: «Артём, тебе хватает на «Набор датчиков для Arduino»!», печать-звезда «шлёпается» (scale 1.4 → 1, 250 мс), кнопка «Покажу учителю». Это тот самый момент радости, которого не хватало старой версии.

## Панель учителя

**T1. Журнал как ведомость**
- Верхняя панель белая с тонкой линией снизу. Вкладки — сегментный переключатель на чернилах.
- Панель урока одной строкой: дата · «Банк дня 7 / 10» с 10 точками-звёздочками (потраченные заливаются золотом) · справа меню «Импорт / Экспорт», а не три кнопки.
- Классы — вкладки-закладки, как в бумажном журнале. «+ Класс» в конце ряда.
- Таблица ученика:
  - зебра `--color-surface-2`, высота строки 56 px, № в Literata;
  - ввод звёзд: 5 звёзд-кнопок 28 px + поле числа. С клавиатуры: цифры 0–5 ставят значение, ↑/↓ — соседний ученик;
  - баланс — золотая пилюля. При изменении рядом серым показывается «39 → 44»;
  - колонка «Вход» свёрнута до кода и статуса. Логин и пароль — во всплывающем окне по клику на код;
  - действия: видны «QR» и «Выдать приз» (иконка + подпись при ширине ≥1280); остальное в «⋯»: «Показать пароль», «Перевыпустить вход», «Скрыть из рейтинга», «Удалить» (красным, с подтверждением).
- Нижняя липкая панель: «Итог урока: 23 ★ · 8 учеников» и главная кнопка «Завершить урок и начислить». Перед начислением — диалог-итог T1a.

**T2. Призы**
- Сетка 4 колонки, фото 4:3, цена — пилюля.
- Действия в правом верхнем углу карточки появляются при наведении, а на планшете видны всегда.

**T2a. Модалка приза:** поля в одну колонку, превью фото 4:3 с подписью «Лучше всего — снимок реального приза», категория сегментами (Небольшой / Средний / Большой), а не выпадающим списком.

**T0. Вход:** лист бумаги с печатью-звездой. Подсказка про `.env` свёрнута в «Где взять пароль?».

## Печать (T4)
- Белый фон, только чёрные чернила + один спот-цвет (зелёный), который в ч/б становится серым 60%.
- Рамка карточки — тонкая двойная линия, как у грамоты. В углу печать-звезда.
- QR 32 мм, код крупно моноширинным; блок «Без Telegram — через сайт» отделён пунктиром.
- 8 карточек на А4, метки реза по углам.

## Движение
Сдержанно: 150–200 мс, `ease-out`. Анимируются только печать-штамп, раскрытие мини-шапки и смена вкладок (сдвиг 8 px + прозрачность). Без конфетти: здесь праздник — это печать.

## Не делать
- Засечки в мелком тексте, таблицах и кнопках.
- Больше одного акцентного цвета, кроме золота.
- Бежевый на бежевом без границы: карточки всегда с линией `--color-line`.
- Эмодзи в интерфейсе.
