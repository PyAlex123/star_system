# «Звёзды» · модуль «Мониторинг» — описание и техническое задание

> Документ для Claude Code. Читать вместе с `CLAUDE.md` и `docs/design/00-brief-obshchiy.md`.
> Технологии и структура кода — как в текущем проекте. Новые фреймворки и сервисы не добавлять без согласования.

## 1. Что это и зачем

«Мониторинг» — новый раздел системы «Звёзды». За 1–2 минуты урока учитель собирает обратную связь (настроение, понимание, оценка урока) и проверяет знания (тесты).
Ученики подключаются по одной постоянной ссылке, без регистрации и пароля. Результаты сразу видны учителю и выгружаются в Excel.

Принципы:
- **Быстро.** Запуск готового опроса — до 3 кликов у учителя; короткий опрос — 3 касания у ученика.
- **Одна ссылка.** Адрес не меняется, его можно повесить в кабинете в виде QR.
- **Открыто для всех.** Ответить может любой ученик, даже если его нет в базе.
- **Один конструктор.** Тест — это опрос, у вопросов которого есть правильные ответы.
- **Сравнимость.** Стандартные вопросы не меняются, их результаты сравниваются между уроками.

## 2. Основные понятия

- **Форма** — набор вопросов с настройками. Создаётся один раз, запускается много раз.
- **Вопрос** — текст, тип, варианты, обязательность; по желанию правильный ответ и баллы.
- **Стандартный вопрос** — из встроенной библиотеки, с постоянным номером (С1–С15); текст не редактируется.
- **Запуск** — проведение формы: классы, тема и цели урока, окно времени, код урока, статус.
- **Участник** — фамилия, имя, класс; связь с учеником из базы или пометка «гость».
- **Ответ** — ответ участника на вопрос; для теста — верно/неверно и баллы.

## 3. Ученик: одна ссылка `/m`

Работает на телефоне 360–430 px, на общем компьютере и внутри Telegram.

1. **Ожидание.** Нет активного запуска → «Подожди, учитель скоро начнёт». Страница сама проверяет каждые 5 секунд и открывает опрос, как только учитель нажал «Запустить».
2. **Вход — один экран:** Фамилия, Имя, Класс (выпадающий список), код урока (если включён) → «Начать». В списке классов — выбранные при запуске; если не выбраны — все классы школы.
3. **Запоминание.** На том же устройстве в следующий раз: «Ты — Иванов Артём, 5-А? [Да] [Это не я]».
4. **Вопросы по одному на экран**, прогресс «2 из 5». На шкалах, лицах и светофоре касание сразу переводит дальше; для остальных типов — «Назад» и «Далее».
5. **Готово.** «Спасибо! Ответы отправлены», результат (если разрешён), кнопка «Следующий ученик».
6. **Закрыто.** После окна: «Опрос закрыт в 14:20», ответы не принимаются.

## 4. Учитель

Новая вкладка в верхней панели: **Журнал · Призы · Уроки · Мониторинг**.

**4.1 Список форм.** Вкладки «Стандартные наборы» и «Мои формы». Действия: Запустить, Изменить,
Копировать, Результаты; удаление — в меню «⋯» с подтверждением.

**4.2 Конструктор.**
- Колонка карточек вопросов; рядом превью «как увидит ученик» на телефоне.
- «+ Вопрос» (выбор типа) и «+ Из библиотеки» (панель стандартных вопросов, клик — добавить).
- Перетаскивание для порядка, копирование и удаление вопроса.
- В вопросе: текст, тип, варианты, «Обязательный», вариант «Другое: ___».
- Переключатель «Правильный ответ» и баллы для типов «один вариант», «несколько», «короткий ответ». Для короткого ответа — несколько допустимых написаний.
- Подстановки в тексте `{тема}` и `{цель}` заполняются при запуске.
- Настройки формы: тип «Опрос/Тест» (задаёт значения по умолчанию); показывать имена в ответах о настроении (по умолчанию — нет, только сводка);
  перемешивать вопросы и варианты; что показать ученику после отправки: ничего / балл / балл и правильные ответы.
- Автосохранение черновика; предупреждение при уходе с несохранёнными изменениями.

**4.3 Запуск (диалог).** Форма → классы (один или несколько) → тема и цели (по строке на цель, если есть подстановки) → время: сейчас на 5/10/15/20/45 мин или до ручного закрытия → код урока вкл/выкл → «Запустить».
Несколько запусков для разных классов могут идти одновременно; ученик попадает в нужный по выбранному классу.

**4.4 Живой экран (для проектора).** Крупно: ссылка, QR, код урока, таймер, «Ответили 18».
Список участников в реальном времени: гости помечены, повторы ФИО подсвечены. Кнопки: «+5 минут», «Завершить», убрать участника.

**4.5 Результаты.**
- По каждому вопросу: диаграмма долей, среднее для шкал, список текстовых ответов.
- Таблица «участник × вопрос», баллы для тестов, сортировка, фильтр по классу.
- Выгрузка в Excel: лист сводки и лист всех ответов.
- Запуск привязан к уроку во вкладке «Уроки» (дата + класс).

## 5. Типы вопросов

| Тип | Как выглядит у ученика | Правильный ответ |
|---|---|---|
| Настроение | 5 нарисованных лиц: Отлично · Хорошо · Нормально · Не очень · Плохо | нет |
| Шкала | 1–5 или 1–10, подписи на краях | нет |
| Светофор | зелёный · жёлтый · красный, у каждого текст | нет |
| Один вариант | крупные кнопки; заготовки «Да/Нет», «Да/Почти/Нет» | да |
| Несколько вариантов | флажки | да |
| Короткий ответ | одна строка | да, несколько написаний |
| Развёрнутый ответ | многострочное поле | проверяет учитель (этап 2) |

Лица и светофор — векторные рисунки, не эмодзи. Звёзды в шкалах не использовать: в системе это валюта.

**Выходной билет** — С15, С6, С7, С8 + 1–3 своих вопроса · **Большая рефлексия** — С2, С10–С14.

## 7. Ученики из базы и гости

- После входа система ищет ученика в выбранном классе по фамилии и имени — без учёта регистра, лишних пробелов и разницы «ё/е».
- Найден ровно один — участник связан с учеником. Иначе — «гость».
- Учитель одним действием связывает гостя с учеником или добавляет его в класс. Автоматически никого не добавлять.

## 8. Правила

- Ответы принимаются только пока запуск открыт; время проверяет сервер, а не устройство ученика.
- Каждый ответ сохраняется сразу. При потере связи ответы хранятся на устройстве и досылаются позже.
- Повтор ФИО в одном запуске не блокируется, а помечается для учителя.
- Код урока — 4 цифры, действует только в своём запуске.
- Ссылка `/m` не показывает списки учеников и чужие ответы; результаты видит только учитель.
- Удаление запуска с ответами — с отдельным подтверждением.

## 9. Связь с текущей системой

- Использовать существующие школы, классы, учеников и уроки; их структуру и поведение не ломать.
- Логику начисления звёзд не менять. Звезда за участие (этап 2) — через существующий механизм, только связанным ученикам, один раз за запуск, за факт участия, а не за содержание ответов.
- Внешний вид — по выбранному дизайн-варианту и токенам проекта; действуют все требования брифа `00`: русский язык, склонения, доступность, Telegram, никаких эмодзи-кнопок.

## 10. Этапы

| Этап | Состав |
|---|---|
| 1 | `/m` с ожиданием и входом; библиотека С1–С15 и 4 набора; конструктор с 7 типами и правильными ответами; запуск; живой экран; результаты и Excel |
| 2 | Звезда за участие; проверка развёрнутых ответов (один вопрос — сразу у всех); связь гостей; графики стандартных вопросов по урокам; импорт вопросов из Excel; уведомление в Telegram-боте о запуске |
| 3 | Личный таймер теста; тепловая карта класса; анализ по заданиям; роль завуча и сравнение классов |

## 11. Критерии приёмки этапа 1

- Учитель запускает «Пульс за 30 секунд» для 5-А не больше чем за 3 клика.
- Ученик с заранее открытой `/m` видит вопросы не позже чем через 5 секунд после запуска, без перезагрузки.
- Ученик, которого нет в базе, проходит опрос и виден учителю как «гость».
- После закрытия окна новые ответы не принимаются, даже если страница была открыта.
- Тест считает баллы; в Excel есть сводка и все ответы.
- Экраны ученика проверены на 360, 390 и 430 px, учителя — на 1280 и 1440 px.
- Журнал, призы, уроки и начисление звёзд работают как раньше.

## 12. Порядок работы

1. Изучи проект: школы, классы, ученики, уроки, вход ученика, панель учителя.
2. Предложи план этапа 1 (новые данные, страницы, затронутые файлы), покажи и жди подтверждения.
3. Делай по шагам: данные → `/m` → конструктор → запуск и живой экран → результаты и Excel.
4. После каждого шага — проверка в браузере со скриншотами; в конце — критерии из раздела 11.
5. Если что-то неясно — спрашивай, не додумывай.
