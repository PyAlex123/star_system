# ⭐ Школьная система наград

Учитель ставит звёзды за уроки, дети видят свой баланс, место в рейтинге класса и копят
на призы. Вход для детей — только через Telegram: ребёнок сканирует QR со своей карточки,
попадает в бота и одной кнопкой открывает личный кабинет.

```
Карточка с QR  →  Telegram-бот  →  кнопка «Зайти в свой кабинет»  →  кабинет (Web App)
```

---

## Что внутри

**Панель учителя** (`/`, закрыта паролем)
- журнал урока: до 10 ⭐ на класс за урок, до 5 ⭐ одному ученику;
- классы, ученики, импорт из Excel/CSV, выгрузка CSV;
- выдача призов и списание звёзд;
- витрина призов: добавить, изменить, скрыть, **загрузить своё фото**;
- печать карточек класса с QR-кодами;
- для каждого ученика: показать QR, открыть **его кабинет глазами ученика**, выпустить
  новый код, отвязать Telegram, сбросить аватар.

**Кабинет ученика** (`/app`, Telegram Web App)
- баланс звёзд и прогресс до ближайшего приза;
- **топ-5 класса** с пьедесталом; если ученик не в пятёрке — его строка показывается отдельно,
  плюс подсказка, сколько звёзд до следующего места;
- витрина призов с фотографиями и прогрессом;
- история начислений и списаний;
- **аватар**: 16 готовых персонажей, своё фото или фото профиля Telegram;
- светлая и тёмная тема, внутри Telegram — по теме пользователя.

## Быстрый старт

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt

cp .env.example .env        # заполните TEACHER_PASSWORD
.venv/Scripts/python.exe app.py
```

Откройте http://localhost:8000 — попросит пароль учителя.
Если `TEACHER_PASSWORD` в `.env` пуст, временный пароль печатается в окне сервера при запуске.

Фотографии призов и аватары уже лежат в репозитории. Пересоздать их можно так:

```bash
.venv/Scripts/python.exe scripts/make_avatars.py        # 16 SVG-аватаров
.venv/Scripts/python.exe scripts/fetch_prize_photos.py  # фото товаров -> WebP
```

## Подключение Telegram-бота

### 1. Создайте бота

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`.
2. Задайте имя (видят дети, например «Звёзды школы») и username (например `school_stars_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AA...`.

Впишите в `.env`:

```ini
BOT_TOKEN=1234567890:AA...
BOT_USERNAME=school_stars_bot
```

Настраивать Menu Button в BotFather не нужно — кнопка приходит прямо в сообщении бота.

### 2. Дайте кабинету адрес в интернете

Telegram Web App открывается **только по HTTPS**. Для проверки поднимите туннель:

```bash
tools/cloudflared.exe tunnel --url http://localhost:8000
```

Cloudflared напечатает адрес вида `https://что-то.trycloudflare.com`. Впишите его в `.env`:

```ini
BASE_URL=https://что-то.trycloudflare.com
```

и перезапустите сервер. Адрес меняется при каждом запуске туннеля — просто обновляйте `BASE_URL`.

### 3. Раздайте карточки

1. В панели учителя выберите класс → **🖨 Карточки класса** → Печать.
2. Разрежьте лист и раздайте детям.
3. Ребёнок наводит камеру на QR → открывается бот → кнопка **«Зайти в свой кабинет»**.

Если камера не читает QR, ребёнок отправляет боту код с карточки (8 символов) — результат тот же.

**Карточка привязывается к первому аккаунту, который её отсканировал.** Чужой аккаунт получит
отказ. Потерял карточку — учитель жмёт ♻️ в журнале: старый код умирает, печатается новый.

## Боевой сервер (свой домен)

```bash
docker compose up -d --build
```

Перед этим в `.env`:

```ini
BASE_URL=https://ваш.домен
DEV_LOGIN=0
TEACHER_PASSWORD=длинный-пароль
```

Поставьте перед контейнером nginx с сертификатом (Let's Encrypt), проксируя 443 → 8000.
При большом числе детей переключите бота на webhook: `USE_WEBHOOK=1`.

> Docker-сборка **не проверялась локально** — на машине разработки Docker не установлен
> (нужны права администратора). Файлы `Dockerfile` и `docker-compose.yml` написаны по
> стандартной схеме, но первый запуск на сервере стоит посмотреть глазами.

## Настройки `.env`

| Параметр | Зачем |
|---|---|
| `BOT_TOKEN` | токен от @BotFather. Пусто → бот не запускается, сайт работает |
| `BOT_USERNAME` | имя бота без `@`, из него собираются ссылки в QR |
| `BASE_URL` | публичный HTTPS-адрес кабинета |
| `TEACHER_PASSWORD` | пароль в панель учителя |
| `JWT_SECRET` | подпись сессий. Пусто → создаётся файл `.jwt_secret` |
| `SCHOOL_NAME` | печатается на карточках |
| `DEV_LOGIN` | `1` — вход в кабинет без Telegram: `/app?dev=<id>`. **На сервере держите `0`** |
| `USE_WEBHOOK` | режим бота: `0` — long polling, `1` — webhook |

## Как устроен проект

```
app.py                  точка входа (python app.py / uvicorn app:app)
backend/
  main.py               сборка FastAPI, запуск бота, заголовки кеша
  config.py             чтение .env
  db.py                 JSON-база: миграции, блокировка, атомарная запись
  security.py           проверка подписи Telegram initData, сессии, доступ учителя
  images.py             обработка загруженных картинок (Pillow)
  schemas.py            модели запросов
  routers/
    auth.py             вход: Telegram, учитель, отладочный
    teacher.py          классы, ученики, уроки, списание
    prizes.py           витрина призов и загрузка фото
    me.py               кабинет ученика: рейтинг, призы, аватар
    cards.py            QR-коды и печать карточек
  bot/
    bot.py              запуск/остановка бота внутри FastAPI
    handlers.py         /start с кодом, привязка, кнопка кабинета
static/
  teacher.html app.html login.html
  css/ theme.css app.css teacher.css cards.css
  js/  teacher.js app.js
  img/prizes/  img/avatars/  fonts/  uploads/
scripts/
  make_avatars.py        генератор SVG-аватаров
  fetch_prize_photos.py  загрузка фотографий призов
```

Данные лежат в `stars_db.json` рядом с `app.py`. Это обычный JSON — его можно открыть
и починить руками. Загруженные фотографии — в `static/uploads/`.
**Резервная копия = копия `stars_db.json` и папки `static/uploads/`.**

## Безопасность

- Панель учителя закрыта паролем (сессия в httpOnly-cookie на 12 часов).
- Ученик получает **только свои данные** и топ-5 своего класса; полный список школы
  (`/api/state`) доступен лишь учителю.
- `initData` из Telegram проверяется по подписи HMAC-SHA256 и не принимается старше 24 часов.
- Загружаемые картинки проверяются Pillow и пересохраняются в WebP — файл с чужим
  расширением внутрь не попадёт. Лимит 5 МБ.
- `DEV_LOGIN` по умолчанию выключен; при включённом сервер пишет предупреждение в консоль.
