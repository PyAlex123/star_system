## Дизайн
Источник: `docs/design/HANDOFF-Zvezdy.md`. Темы: notebook · quest · sky · clear · sticker (все в проде),
тема — у каждой школы (`school.theme`). Приоритет: макеты `.dc.html` + `tokens.css` > `uploads/01–05` > `00-brief`.
- Стили — только `var(--…)` из `static/css/tokens.css` (копия `docs/design/tokens.css`, значения не менять);
  новых hex, px-теней и шрифтов в шаблонах нет. Состояния — через `color-mix()` из токенов.
- Тема — `<html data-theme>`, рендерится сервером (`backend/themes.py`). clear: `data-mode`.
  sky: ученик — `data-night`, вход учителя — `data-night` + `data-day`. Печать: `data-light`.
- Различия разметки между темами — переключатели `--show-*`/`--ov*` и ветки по теме в JS, а не копии экранов.
- Каркас панели учителя — меню разделов сбоку и журнал с плиток «Сегодня» (решение владельца 26.11.2026,
  расходится с макетом T1 сознательно); компоненты и токены — по макету.
- Шрифты — локальные woff2 в `static/fonts/`, Google Fonts не использовать.
- Иконки — инлайн-спрайт `static/img/icons.svg` (Lucide). Эмодзи не использовать как кнопки. ★ всегда рядом с числом.
- Склонения: «1 звезда / 2 звезды / 5 звёзд».
- Не менять бэкенд, API и логику начисления/списания звёзд без прямой просьбы.
- После правки UI — проверка 390×844 и 1440×900 во всех 5 темах + clear dark; печать — PDF А4.
  Компоненты всех тем — страница `/_ui?theme=…` (администратор).
- `prefers-reduced-motion` отключает анимации (в `tokens.css`).
- Без служебных надписей на экранах (`.env`, имена переменных) — это проверяет `tests/test_service_texts.py`.
